Останнє оновлення: 15 серпня 2026

Цей бот Discord (“Бот”) поважає конфіденційність користувачів та прагне захищати будь-які дані, які можуть оброблятися під час використання сервісу.

1. Які дані можуть збиратися

Бот може обробляти:

Discord User ID
Server ID
Channel ID
повідомлення та команди, необхідні для роботи функцій Бота
тимчасові технічні дані та логи помилок
2. Як використовуються дані

Дані використовуються виключно для:

забезпечення роботи функцій Бота
обробки команд
покращення стабільності та безпеки
запобігання зловживанням
3. Зберігання даних

Бот не продає та не передає персональні дані третім особам.
Дані можуть зберігатися лише стільки, скільки потрібно для роботи функцій Бота.

4. Безпека

Вживаються розумні заходи для захисту даних від несанкціонованого доступу.

5. Сторонні сервіси

Бот використовує платформу Discord, тому користувачі також погоджуються з:

Умовами використання Discord
Політикою конфіденційності Discord
6. Контакти

Якщо у вас є питання щодо конфіденційності, зверніться до власника Бота через Discord.
